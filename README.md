# LoaderLens 📚

A student academic planner to organize tasks, track deadlines, and manage academic priorities.

## 🌐 Live Demo

[Open LoaderLens](https://2k25cse2512438-creator.github.io/LoaderLens/)

## ✨ Features

- Add academic tasks with subjects, categories, deadlines, and priorities
- Edit and delete tasks
- Mark tasks as completed
- Search tasks by name or subject
- Filter tasks by category and completion status
- Sort tasks by priority and nearest deadline
- Dashboard showing task statistics
- Upcoming deadlines overview
- Save tasks in browser Local Storage

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- GitHub Pages

## 🚀 Getting Started

1. Open the live demo using the link above.
2. Add a task with its subject, category, deadline, and priority.
3. Search, filter, or sort tasks as needed.
4. Mark tasks as completed when finished.

## 💾 Data Storage

LoaderLens uses browser Local Storage to save tasks. Tasks are stored in the browser on the device being used and do not automatically sync across different browsers or devices.

## 🎯 Project Goal

The goal of LoaderLens is to make academic task management easier by helping students organize their workload and keep track of upcoming deadlines.
